#ECHO

The project is currently under continuous development, with ongoing improvements in performance, UI/UX, and architecture, and a more advanced version (v2) is planned to include additional features, better optimization, and a more scalable structure.

Social Media App is a modern web application built with React, styled using Tailwind CSS, and powered by HeroUI v2 components, with state management handled through the Context API to ensure a clean and scalable structure. The app allows users to create, edit, and delete posts and comments within a responsive and interactive interface
